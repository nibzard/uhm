# v0.6.6 — fix history export, the --shell help, and installer override docs

v0.6.6 is a small patch of correctness fixes surfaced by real-user QA of v0.6.5.
The only behavior change is the `history export` fix described below; there are
no output-format or telemetry-contract changes.

## What changed

### `history export` honors its destination

`history export <path>` previously dropped the positional destination and always
wrote `./uhm-history.redacted.jsonl`, reporting success. It now accepts a
positional destination or `--output <path>`, defaults only when neither is
given, and errors (exit 2) on a missing `--output` value, on both forms given
at once, or on more than one positional. It also tolerates the documented `--`
separator, matching the neighboring `history search` command.

### `--shell` help lists every accepted shell

The `--help` synopsis listed `auto|bash|zsh|fish|pwsh`; the parser also accepts
`sh` and `powershell`. It now lists all seven values.

### Installer override examples corrected

The override one-liners in `docs/install.md` placed the `UHM_*` variable before
`curl`, where `curl` ignores it and the override silently does nothing. They now
place it after the pipe (`curl ... | UHM_X=val sh`) so it reaches the installer
process, with a note explaining the placement.
