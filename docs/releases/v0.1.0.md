# uhm v0.1.0

The first public release turns one natural-language terminal intent into one bounded local job and returns the useful result.

## What ships

- Official OpenAI Responses API with four strict local action routes.
- Result-first child-shell execution with exact piped bytes, native terminal streams, bounded redirected diagnostics, timeouts, signal status, and one optional clarification/revision/repair slot.
- `standard` outbound context by default; inspect it with `uhm context show` or minimize it with `--context minimal`.
- Metadata-only local receipts enabled by default, bounded to 500 records or 30 days. Clear them with `uhm history clear`.
- Content-free aggregate telemetry enabled by default after a one-time notice. It sends only coarse enum categories through Cloudflare and can be disabled with `uhm telemetry off`, `--no-telemetry`, `UHM_TELEMETRY=off`, or `DO_NOT_TRACK=1`.
- `uhm telemetry preview|status|on|off`, explicit `uhm feedback good|bad`, and a private best-effort queue capped at 20 summaries or seven days. Workers Analytics Engine retains raw accepted categories for three months; there is no stable identity or cross-run join key.
- `uhm doctor` for local configuration and terminal checks, plus an explicit `uhm doctor network` OpenAI reachability/authentication check.
- Plain, no-color, and no-motion modes with display-cell-aware narrow-terminal layout.
- Native archives for Linux musl and macOS on x86_64 and arm64, with SHA-256 checksums and GitHub build-provenance attestations.

## Execution policy

Ordinary actions run immediately. Detected deletion, privilege elevation, remote mutation, process control, or uncertain effects pause unless `--force` is explicit. These warnings are advisory and are not a sandbox or safety guarantee. Exit code zero is process evidence, not proof the intent was satisfied.

Persistent parent-shell actions such as `cd`, `export`, aliases, and activation are generated exactly but not applied by the base binary; copy or evaluate them in the current shell. Automatic shell integration is deferred.

OpenAI receives the prompt, explicitly piped UTF-8 input, and selected context. Requests set `store: false`, though OpenAI's default abuse-monitoring retention still applies unless the API organization has different approved controls. Cloudflare processes telemetry HTTPS connections, but the CLI payload and Worker application data contain no IP, content, exact client time, path, or stable identifier. Read [PRIVACY.md](../../PRIVACY.md) for the exact boundary.

## Limits

Linux and macOS are supported; native Windows is not. uhm is not a background agent, does not provide universal undo, and does not sandbox model-generated commands. macOS archives are not Developer ID signed or notarized in this release, so the first-download quarantine journey may require an explicit user approval.

The `uhm-cli` crate passes packaging and publish dry-run checks. Publishing it to crates.io is deferred until registry ownership is ready; GitHub binaries are the supported first-release channel.
