# v0.3.2 — fail-closed review and release hardening

v0.3.2 is a security-focused patch release addressing the findings from the v0.3.1 clean-room black-box assessment.

- **Fail-closed terminal review.** EOF, terminal hangup, and input read errors at shell and generated-program review prompts now cancel with status 11 instead of selecting Run.
- **Conservative metadata authorization.** Non-interactive `touch`, `chmod`, and `chown` proposals pause for explicit authorization; the CLI and behavior documentation now state this policy directly.
- **Rootless-safe installation.** Release archives are extracted without attempting to preserve archive ownership, including in the published installer and manual installation instructions.
- **Consistent audit metadata.** Every history event records the full application version, and a corrupt journal produces one actionable warning per invocation.
- **Reliable first-use coordination.** Concurrent first requests serialize disclosure rendering so the one-time notice appears once.
- **Clearer diagnostics and disclosure metadata.** Local aliases no longer receive model-origin errors, and context disclosure labels its minimization configuration as guidance rather than active state.

Verification included the complete Rust test suite, strict Clippy, formatting and documentation checks, installer syntax validation, an optimized release build, PTY EOF regression tests through `script(1)`, and a 20-process first-use concurrency test.
