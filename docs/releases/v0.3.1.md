# v0.3.1 — prose routing and evaluation hardening

v0.3.1 is a patch release that makes prose-only requests more reliable and turns the v0.3.0 tmp-drive evaluation into durable, repeatable release evidence.

- **Reliable piped `ask` and `explain`.** Prose-only routes now expose only answer and clarification tools to OpenAI and Cerebras, preventing valid summaries from drifting into execution proposals while retaining the local route check as defense in depth.
- **Fewer unnecessary clarifications.** Prompt contract v12 directs the planner to discover file formats and schemas through the requested read action instead of asking users for facts available in named inputs.
- **Clear automation guidance.** CLI help and documentation explain non-TTY mutation pauses, status 11, and the `--dry-run` then `--force` workflow. Route-contract errors include a concrete next step.
- **Durable evaluation evidence.** The v0.3.0 scenario definitions, assertions, expected values, structured results, raw streams, and SHA-256 manifest are checked in with a configurable three-pass runner.
- **Stronger reporting.** The evaluation report now distinguishes scenario conformance from capability coverage, uses end-to-end latency terminology, records model configuration and limitations, and avoids reclassifying the original piped-`ask` failure as a pass.

Verification included the complete Rust test suite, clippy with warnings denied, documentation synchronization, evidence-integrity checks, a three-pass live battery, and focused 3/3 reruns of the two model-routing cases improved in this release.
