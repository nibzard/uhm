# Bounded Python programs

UHM may choose one standard-library Python program when structured parsing, statistics, or multifile logic would be contorted as a shell pipeline. The program remains one bounded job and runs with your user authority; it is not a sandbox.

Choose the page that matches what you need:

- [Process local data without sending its contents](tutorials/local-data.md) — learn the program route through a complete exercise.
- [Program contract reference](reference/program.md) — look up resource modes, helper access, preflight rules, limits, environment, and outcomes.
- [Why UHM generates bounded programs](explanation/program-execution.md) — understand the design and its tradeoffs.
- [Recover prior work](how-to/recover-work.md) — operate on managed writable artifacts and retained evidence.

The exact invocation and outcome rules remain normative in the [behavior contract](behavior-contract.md).
